このサイトについて

はじめに

プロジェクトの概要

このドキュメントサイトは MkDocs を使って構築されています。Markdown で書かれたドキュメントを静的サイトとして公開するためのプラットフォームです。コードサンプルや技術仕様、手順書など、さまざまな種類のドキュメントを管理・公開するために使用できます。

各ページは docs/ ディレクトリ以下に Markdown ファイルとして配置されており、mkdocs.yml の設定に基づいてナビゲーションが構成されます。テーマやプラグインを追加することで、より充実したドキュメントサイトを構築できます。

対象読者

本サイトは、プロジェクトの開発者やドキュメント管理者を主な対象としています。技術的な背景を持つ読者を想定していますが、各トピックの導入部では基本的な概念についても説明しています。

ドキュメントの構成や記述スタイルについては、プロジェクトのガイドラインに従ってください。

環境と構成

セットアップ方法

このプロジェクトはパッケージ管理に uv を使用しています。以下の手順で開発環境をセットアップできます。

  • リポジトリをクローンしてサブモジュールを初期化する
  • uv sync で依存パッケージをインストールする
  • uv run mkdocs serve で開発サーバーを起動する

ローカル環境でサーバーを起動すると、ファイルの変更がリアルタイムでブラウザに反映されます。ドキュメントを執筆しながら仕上がりを確認できるため、効率的に作業を進められます。

デプロイについて

GitHub Pages への公開

ドキュメントは GitHub Pages を通じて公開されます。uv run mkdocs gh-deploy コマンドを実行すると、対象プロジェクトの gh-pages ブランチに自動的にビルド済みサイトがプッシュされます。

デプロイ前に、mkdocs.yml の site_url が正しく設定されていることを確認してください。誤った URL が設定されていると、内部リンクやリソースの参照が正しく機能しない場合があります。

お問い合わせ

このドキュメントに関するご意見やご質問は、GitHub の Issue からお寄せください。改善提案や誤りの指摘も歓迎します。ドキュメントの品質向上にご協力いただける方は、Pull Request を送っていただくことも可能です。
